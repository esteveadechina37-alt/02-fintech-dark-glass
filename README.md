# Plateforme Fintech Dark Mode & Glassmorphism

**Statut : En cours**

Application fintech de démonstration construite avec Next.js 14, TypeScript, Tailwind CSS, Framer Motion et Recharts.

## Écrans

- `/` — Vue d’ensemble, graphique de solde, transactions récentes et calendrier interactif.
- `/comptes` — Soldes des comptes courant, Livret A et PEA.
- `/cartes` — Carte 3D personnalisable et plafonds de paiement/retrait.
- `/transactions` — Historique avec recherche.
- `/investissements` — Aperçu BTC, ETH et actions.

Le menu mobile, la navigation active et les modales d’ajout de compte et de virement sont inclus.

## Démarrage

```bash
npm install
npm run dev
```

Ouvrez [http://localhost:3000](http://localhost:3000) pour afficher le tableau de bord.
